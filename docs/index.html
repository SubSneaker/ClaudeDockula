Live panels next to your Claude Code session.

ClaudeDockula adds a row of tabs above the prompt. Each tab shows a short status from one panel. Click a tab to open a dock with the full panels, beside the conversation or below it.

Install: run these two commands in Claude Code.

/plugin marketplace add SubSneaker/ClaudeDockula
/plugin install claudedockula@dockula

Built-in panels

Each panel has a tab above the prompt and a section in a dock. Click a section's header to open or close it.

  • 🌿

    Branch

    The current branch and its changed files. Guide

  • ✅

    Checks

    The type-check, lint, test or build commands you set for a repo. Press Run to run one. Guide

  • 🕘

    Activity

    The files Claude edited and the tools it called in this session. Guide

  • 🎫

    Jira Off by default

    The ticket for your branch and a board of your tickets. Guide

  • 🐙

    GitGud

    Your pull requests and issues on GitHub, GitLab or Bitbucket Cloud. Guide

  • 💬

    Slacker Off by default

    Your Slack mentions, direct messages and thread replies. Guide

Review a pull request in the background

GitGud can start a separate Claude session that reviews a copy of the pull request. It writes a draft review and posts nothing. If it needs a permission, you answer in the panel.

Read Slack mentions

Slacker shows new Slack messages for you in the dock. You can reply from the panel.

Slacker panel guide

Docks on the right or at the bottom

You can open docks on the right of the conversation, and one dock at the bottom above the prompt. Each dock can have several views and shows its panels in a column or a row. Drag the top edge of the bottom dock to change its height.

Usage guide

Add your own panels

Press ➕ after the tabs above the prompt, or run /dock add, to open the New panel form. Give the panel a name and describe what it shows. You can also choose where its data comes from and how often it refreshes.

Send to Claude puts a prompt in your prompt box. Claude then writes the panel in dockula-panels, a separate plugin in your Claude folder. Updates to ClaudeDockula do not change it.

Your panels get a tab above the prompt and a section in any dock, the same as the built-in panels. On the terminal and in the desktop app you can drag them, right-click them and type in them.

Requirements

  • Claude Code v2.1.275 or later.
  • Right docks need the fullscreen interface. Set "tui": "fullscreen" in your settings.
  • Jira and Slacker are off by default because they need an MCP server. Turn them on in ⚙ Manage.
  • To update, run claude plugin update claudedockula@dockula in your shell, then /reload-plugins in Claude Code.
